# 🤖 Natural Language Query System

## ✅ Feature Complete!

### **What's New:**

The Streamlit app now has an **AI-powered natural language query interface** that allows you to ask questions in plain English and get instant, intelligent responses!

---

## 🎯 How to Use

### **Query Interface Location:**
- **Always visible** at the top of every page
- Look for the **"🤖 Ask Me Anything"** section
- Type your question and click **"🔍 Ask"**

### **Quick Actions:**
After getting a response, you can:
- **📈 Deep Dive** - Jump to detailed stock analysis
- **➕ Add to Watchlist** - Quickly add stock to your watchlist

---

## 📝 Supported Query Types

### **1. Price Queries**
```
"What is the price of RELIANCE?"
"Show me TCS price"
"Current price of INFY"
```

**Response Includes:**
- Current price
- Change percentage
- Real-time data

### **2. Comparison Queries**
```
"Compare TCS and INFY"
"TCS vs WIPRO"
"Compare RELIANCE with HDFCBANK"
```

**Response Includes:**
- Side-by-side comparison
- Price, signals, structure
- RSI and confidence levels
- Recommendation on which is stronger

### **3. Buy/Sell Signal Queries**
```
"Should I buy HDFCBANK?"
"Is it time to sell ICICIBANK?"
"Buy signal for RELIANCE"
```

**Response Includes:**
- Clear recommendation (BUY/HOLD/SELL)
- Confidence percentage
- Market structure and bias
- RSI level
- FVG status
- Detailed reasoning

### **4. Comprehensive Analysis**
```
"Analyze RELIANCE"
"Full analysis of TCS"
"Review INFY"
```

**Response Includes:**
- Technical analysis
- Smart Money Concepts
- Fundamental metrics
- Overall rating

### **5. Fundamental Analysis**
```
"Fundamentals of HDFCBANK"
"Financial metrics for TCS"
"Valuation of RELIANCE"
```

**Response Includes:**
- Company details
- Valuation metrics (P/E, P/B)
- Profitability (ROE, ROA)
- Growth metrics
- Quality score
- Investment rating

### **6. Technical Analysis**
```
"Technical analysis of TCS"
"Chart analysis for INFY"
"SMC analysis of RELIANCE"
```

**Response Includes:**
- Price action
- RSI indicator
- Volume analysis
- Market structure
- SMC bias
- FVG status
- Signal and confidence

### **7. Volume Queries**
```
"Volume of BHARTIARTL"
"Trading volume for ITC"
"Volume analysis of SBIN"
```

**Response Includes:**
- Current volume
- Volume ratio vs average
- Status (High/Normal/Low)
- Volume spike alerts

### **8. Trend Queries**
```
"Trend of ITC"
"Market direction for HINDUNILVR"
"Momentum of WIPRO"
```

**Response Includes:**
- Market structure (Bullish/Bearish/Sideways)
- Bias direction
- Momentum percentage
- Trend strength

### **9. Support/Resistance Queries**
```
"Support levels of HINDUNILVR"
"Resistance for RELIANCE"
"Key levels of TCS"
```

**Response Includes:**
- Current price
- FVG zones
- Active order blocks
- Link to detailed analysis

### **10. Best Stocks/Screening**
```
"Show me best stocks"
"Find good opportunities"
"Top stock picks"
"Screen stocks"
```

**Response Includes:**
- Top 5 opportunities
- Price and change
- Signal and confidence
- Structure and RSI

### **11. Risk Assessment**
```
"Risk of RELIANCE"
"Is HDFCBANK safe?"
"Volatility of TCS"
```

**Response Includes:**
- Risk level (High/Medium/Low)
- RSI level
- Volatility percentage
- Link to detailed risk metrics

### **12. Sector Analysis**
```
"Sector performance"
"Industry analysis"
"Sector momentum"
```

**Response Includes:**
- Sector overview
- Link to detailed dashboard

## 🚀 Technical Details

### **Query Handler:**
- **File:** `nlp_query_handler.py`
- **Pattern Matching:** Regex-based query detection
- **Data Sources:** Market data fetcher, fundamental analyzer, SMC analyzer
- **Response Types:** 14 different query types supported

### **Integration:**
- Always visible at top of app
- Works on all pages
- Persistent across navigation
- Quick action buttons

### **Performance:**
- Cached data where possible
- Parallel stock fetching
- Fast response times
- Error handling
